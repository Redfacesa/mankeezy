Artist site for **Manace Kapinga (Mankeezy)** — album drop and exclusive braai RSVP.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Env

| `VITE_SUPABASE_ANON_KEY` | Supabase anon key |
